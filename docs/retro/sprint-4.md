## 4. 评审与答辩

### 4.1 发布前检查清单（DoD + 9.4 交付物）

- [ ] `develop → main` 发布 PR，≥2 Approve（含 SM 或 PO），CI 全绿
- [ ] `main` 打标签 `v1.0.0` 并推送；创建 GitHub Release（Release Notes 含新功能、已知问题、部署步骤）
- [ ] `docker compose -f deploy/docker-compose.yml up -d --build` 一键部署验证通过（附访问截图）
- [ ] `mvn verify`（含 Testcontainers 端到端）全绿；领域覆盖率 ≥ 70%
- [ ] Swagger UI 全量接口可调；`docs/错误码.md` 与实现一致
- [ ] 全部 Sprint 记录（`docs/scrum/`）与燃尽图齐备
- [ ] ADR 补齐（含 ADR-009 渐进式质量门禁、禁用账号会话清理）
- [ ] 答辩 PPT 与 ≤5 分钟演示视频入 `docs/final/`
- [ ] 个人总结提交教学平台
