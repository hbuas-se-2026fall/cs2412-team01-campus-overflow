## 4. 评审：演示结果与被接受/退回的 PBI

> 评审会尚未召开。以下为**待核查的验收清单**（指导书 6.4.4），评审当天逐条勾选并记录结论。

- [ ] 注册教师账号后悬赏积分为 1000；学生为 0
- [ ] 采纳后数秒内回答者声誉 = 15，流水出现“回答被采纳 +15”，徽章“初露锋芒”；自问自答声誉不变
- [ ] 被赞 +10、被踩 −2、赞改踩 −12；同日正向投票所得超过 200 的部分不计
- [ ] 教师发起 50 分 / 7 天悬赏：可用 950、冻结 50；采纳他人回答后获奖者声誉 +50（`BOUNTY_AWARDED`）、发起人冻结归零
- [ ] 把 `expires_at` 改为过去 + 缩短 `co.reputation.bounty-expiry-interval-ms`，可演示到期退款
- [ ] 排行榜周/月/学期/总榜可切换；`GET /api/v1/admin/reputation/reconciliation` 返回空列表
- [ ] 他人无法查看我的流水（403 `REP-3002`）
- [ ] **事件重放幂等**：把某条 `outbox_event.published_at` 置空重放，声誉/徽章/悬赏/排行榜不重复变化
