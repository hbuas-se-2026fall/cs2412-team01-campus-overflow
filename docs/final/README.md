## 风险与兜底

| 风险 | 影响 | 兜底 |
| :-- | :-- | :-- |
| 演示机器没有 Docker / 起不来服务 | 现场无系统可点 | 提前录好视频；CI 的 `Deploy Smoke` 记录可作「确实跑过」的证据 |
| 网络不稳，依赖外网镜像 | 构建失败 | 提前 `docker pull` 好基础镜像；或用本地已有镜像 |
| 数据被改乱 | 演示数字不对 | `down -v` 重建，`DemoDataSeeder` 恢复 |
| 讲到一半超时 | 问答没时间 | 砍掉 demo 第 10 步（@提及）与第 5 段过程讲解 |

## PPT 结构（与指导书 6.6.2 的演示脚本一致）

1. 产品愿景与团队分工（1 min）
2. 架构：上下文映射、模块结构、一条 ADR 的取舍（2 min）
3. 功能演示：提问 → 回答 → 投票 → 教师认证 → 悬赏 → 采纳 → 声誉徽章 → 排行榜 → 搜索 → 通知（6 min）
4. 质量：CI 历史、覆盖率、端到端测试、事件重放幂等（2 min）
5. 过程：燃尽图、速度、一次典型 PR 评审、回顾改进项（2 min）
6. 问答（2 min）

## 录视频的注意

- 用 `demo` profile 起后端（`DemoDataSeeder` 已可用），避免现场造数据；
- 提前把数据库初始化好，录制时不要出现 Flyway 迁移等待；
- 视频控制在 5 分钟内，超过会被截断；
- 录完自己看一遍，确认没有把终端里的密码、真实学号录进去。

## 个人总结

不放在仓库里，按教学平台要求单独提交。内容建议：负责的 PBI 与 PR、遇到的一个技术问题及解法、一条可改进的地方。
