## 2. 功能演示十步（6 分钟）

用两个浏览器窗口：A = 学生 `2023001`（小明），B = 教师 `T2001`（王老师）。

| # | 角色 | 操作 | 讲解要点 | 预期 |
| --: | :-- | :-- | :-- | :-- |
| 1 | A | 首页 → 「提出一个问题」，标题 ≥10 字、正文 ≥20 字、带标签 | 标题/正文/标签的长度规则来自领域对象 | 新问题出现在列表首位 |
| 2 | B | 打开该问题 → 写一条回答 | 回答正文 ≥10 字 | 回答出现，问题卡片回答数 +1 |
| 3 | A | 给 B 的回答点赞 | 赞 +10、每日上限 200、不能自投 | 分数变化 |
| 4 | B | 对该回答点「教师认证」 | 认证徽章；触发通知 | 回答旁出现认证标记 |
| 5 | B | 在该问题上发起悬赏（如 50 分） | 只有课程管理者能发（`REP-3001`）；积分被冻结 | 问题卡片出现倒计时 |
| 6 | A | 采纳 B 的回答 | 采纳 +15、自答不加分；悬赏结算 | 回答标记「已采纳」，B 的声誉 +65 |
| 7 | B | 打开自己的声誉档案 / 排行榜 | 账本流水、徽章、周榜 | 数字与第 3、6 步对得上 |
| 8 | 任意 | 搜索「跳表」或「红黑树」 | 中文 ngram 检索；单字关键词会被 422 `DIS-1001` | 命中演示数据里的问题 |
| 9 | A | 打开通知铃铛 | 新回答/被采纳/认证/@ 都有通知，未读数正确 | 未读数与列表一致 |
| 10 | A | 评论里 `@王老师` | 提及解析，单条最多 5 人 | B 收到 @ 通知 |

> 第 4 步与第 6 步的顺序可以互换；如果时间紧，砍掉第 10 步。

## 5. 预设问答（2 分钟环节）

| 问题 | 一句话答案 | 展开时引用 |
| :-- | :-- | :-- |
| 为什么是模块化单体而不是微服务？ | 课程规模下分布式事务与运维成本不划算，但用模块边界和 `*-api` 保留了拆分可能 | ADR-001、ADR-009 |
| 为什么用服务端会话而不是 JWT？ | 封禁要立刻生效，JWT 做不到即时失效；Redis 会话还能共享给多实例 | ADR-003、ADR-011 |
| 事件重复投递怎么办？ | 发件箱 + 消费端 `processed_event` + 账本唯一键，三层幂等 | ADR-002、`ReputationReplayIdempotencyTest` |
| 覆盖率门禁怎么定的？ | 领域层 0.75 且 `haltOnFailure=true`，按逐步收紧的质量门禁 | ADR-009 |
| 中文搜索为什么用 ngram？ | MySQL 内置、无需额外组件，代价是索引更大 | ADR-005 |
| 你们的 Scope 怎么控制的？ | 48 条 PBI、163 点，S3 主动把承诺从 42 降到 31 点保质量 | `docs/backlog/product-backlog.md` |

## 6. 失败兜底

| 故障 | 兜底动作 |
| :-- | :-- |
| 现场环境起不来 | 直接放 `demo.mp4`，CI 记录在 Actions 里可查 |
| 网络断 | 用本地 compose（`deploy/docker-compose.prod.yml`），不依赖外网 |
| 数据被改乱 | `down -v` 重建，`DemoDataSeeder` 自动恢复演示数据 |
| 时间超了 | 砍第 10 步与第 5 段的过程讲解，保住功能与质量两段 |
| 老师要求现场调接口 | Swagger UI 全量可调；或用 `docs/postman/` 集合 |
