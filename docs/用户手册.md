# CampusOverflow 用户手册

> 面向**使用者**：学生、教师、助教、管理员。开发与部署请看 [README](../README.md) 与 [deploy/README.md](../deploy/README.md)。
> 适用版本：`v0.9.0`（RC）。`v1.0.0` 发布后若有交互变化，本文件同步更新。

## 1. 角色能做什么

| 角色 | 典型操作 |
| :-- | :-- |
| 学生 | 浏览 / 搜索问题，提问、回答、投票、评论；采纳自己问题的答案 |
| 教师 | 以上全部；认证优质回答、编辑或删除课程内内容、发起悬赏、创建课程 |
| 助教 | 同教师（课程内管理与认证），由教师在课程内授予 |
| 管理员 | 创建教职工账号、认证学生身份、调整角色、禁用违规账号（禁用后立刻下线） |

> 页面上的按钮会按角色与身份显示；看不到某个按钮，通常是权限或未认证，而不是浏览器问题。

## 2. 注册与登录

**注册**（`POST /api/v1/auth/register`）

| 字段 | 规则 | 违反时的错误码 |
| :-- | :-- | :-- |
| 学号 / 工号 | 4–20 位字母或数字，登录凭据，不对外展示 | `ID-1001` |
| 昵称 | 2–20 位，不能含 `@` 与空格；全局唯一，用于 `@提及` | `ID-1002` / `ID-2002` |
| 邮箱 | 格式合法、≤100 字符、唯一 | `ID-1003` / `ID-2003` |
| 密码 | 8–64 位，必须同时含字母与数字 | `ID-1004` |
| 学院 / 班级 | 可选，各 ≤50 字符 | — |

注册后为**学生**且**未认证**；管理员认证后昵称旁显示认证标记。

**登录**：学号 + 密码。短时间内多次失败会被临时锁定（约 1 分钟），返回 429，属正常保护。

**会话**：登录态保存在 `HttpOnly` 的 `SESSION` Cookie 中，30 分钟无操作过期；登出即时失效。

## 3. 浏览与搜索

- **列表**（`GET /api/v1/questions`）：按课程、标签筛选，只看未回答；排序支持 `newest`（默认）/ `votes` / `answers`。
- **搜索**（`GET /api/v1/search`）：中文按 `ngram` 分词，支持 `q` 关键词 + 标签 / 未回答 / 悬赏筛选；排序支持
  `relevance`（默认）/ `newest` / `active` / `hot`。
- 关键词**少于 2 个字符**会被拒绝（422 `DIS-1001`），这是为了避免全表扫描。
- 已删除的问题不会出现在列表、搜索与相关推荐里。

## 4. 提问

- 标题 **10–150** 字（`QA-1001`）；正文 **20–30000** 字，支持 Markdown，代码请用 ```` ``` ```` 包裹（`QA-1002`）；
- 标签 **1–5** 个（`QA-1005`），大小写与前导 `#` 会被归一化；
- 问题可关联课程，便于课程内检索。

## 5. 回答、投票、评论、采纳

| 操作 | 规则 |
| :-- | :-- |
| 回答 | 正文 ≥10 字、≤30000 字；不能回答已删除的问题 |
| 投票 | 赞 **+10**、踩 **−2**；改投按**差值**计算，撤销同理；每日正向所得上限 **200**；不能给自己的内容投票（422 `QA-1015`） |
| 评论 | 支持一层回复；`@昵称` 会解析为提及（单条最多 5 人），昵称不存在会被忽略 |
| 采纳 | 提问者或课程教师/助教可采纳（`QA-3001`）；采纳后回答者 **+15**，**自问自答不加分**；重复采纳 409 `QA-2002`；已删除的回答不能被采纳（`QA-1008`） |
| 编辑 / 删除 | 作者本人或课程教师/助教；删除为软删除，历史与审计保留 |

## 6. 教师认证

教师或助教可以对优质回答做「认证」，回答旁显示认证标记，并给作者发送通知。认证过的回答在排序中更靠前。

## 7. 悬赏

- 只有**课程管理者**（该课程的教师）可以发起悬赏（403 `REP-3001`），发起时冻结相应积分；
- 问题被采纳时结算给获奖回答，到期未采纳则**退款**给发起者；
- 悬赏进行中会在问题卡片上显示剩余时间。

## 8. 声誉与排行榜

- 声誉按「只追加账本」记录，每一次加减都有流水可查（个人主页 → 声誉流水）；
- 排行榜支持**周 / 月 / 学期 / 总**四个维度；
- 达到里程碑自动获得徽章。

## 9. 通知

- 触发场景：新回答、回答被采纳、回答被认证、悬赏获奖、获得徽章、被 `@提及`；
- 顶部铃铛显示未读数（当前为 30 秒轮询刷新，SSE 实时推送在 S4 规划中）；
- 支持单条已读与全部已读，只能操作**自己**的通知（越权返回 403 `DIS-3001`）。

## 11. 常见问题

| 现象 | 原因 | 处理 |
| :-- | :-- | :-- |
| 登录接口返回 200，但刷新后又是未登录 | 纯 HTTP 环境下发了 `Secure` Cookie，浏览器丢弃 | 部署时把 `COOKIE_SECURE` 设为 `false`（HTTPS 环境保持 `true`） |
| 中文搜索没有结果 | 数据库不是按 `ngram_token_size=2` 初始化的 | 用 `deploy/docker-compose.prod.yml` 起的 MySQL，不要换成自建库 |
| 访问已删除的问题返回 422 `QA-1008` | 设计如此，不是 404 | 见 [ADR-010](adr/010-已删除内容的错误码.md) |
| 单字关键词搜不到，返回 422 `DIS-1001` | 关键词至少 2 个字符 | 加长关键词 |
| 点「采纳」提示无权限 | 只有提问者或课程教师/助教可以采纳 | 换账号或请老师操作 |
| 连续登录失败后提示「请 1 分钟后再试」 | 登录限流 | 等 1 分钟 |
| 页面上看不到管理入口 | 当前账号不是管理员 | 用 `admin01` 或请管理员授权 |

## 12. 错误码

完整的错误码与 HTTP 状态映射见 [docs/错误码.md](错误码.md)。响应格式遵循 RFC 9457 Problem Details：

```json
{ "type": "about:blank", "title": "Unprocessable Entity", "status": 422,
  "detail": "不能给自己的内容投票", "code": "QA-1015" }
```
