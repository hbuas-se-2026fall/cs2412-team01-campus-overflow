# CampusOverflow v0.2.0 — Sprint 1 问答核心

## 概述
学生可以完成“提问 → 回答 → 投票 → 评论 → 采纳”的完整问答闭环，教师可以认证与删除内容。

## 新功能
- **提问**（PB-06）：发布带标签、可关联课程的问题；标签自动转小写、去 `#`、去重（最多 5 个）。
- **问题列表与详情**（PB-07、PB-08）：分页浏览；详情页渲染并净化 Markdown，回答按“已采纳 → 得分 → 时间”排序。
- **回答**（PB-09）：对未删除的问题提交回答，问题回答数原子递增。
- **采纳**（PB-10）：提问者或课程教师/助教采纳最佳答案，每题只能采纳一次。
- **投票**（PB-11）：对问题和回答点赞、踩或取消；不能给自己投票，重复投相同的票时幂等。
- **编辑与删除**（PB-12、PB-13）：作者或课程管理者可编辑；作者只能删除尚无回答的问题，已被采纳的回答不能由作者删除。
- **教师认证**（PB-14）：课程教师/助教可以认证回答。
- **评论与回复**（PB-15）：支持一级回复，正文 2–600 字。
- **前端**（PB-19）：根据权限显示编辑、删除、采纳、认证按钮，并按错误码给出提示。

```bash
cd backend && mvn spring-boot:run -pl co-bootstrap -Dspring-boot.run.profiles=dev
cd frontend && npm install && npm run dev   # http://localhost:5173
```
