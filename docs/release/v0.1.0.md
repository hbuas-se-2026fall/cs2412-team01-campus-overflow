## 这一版有什么

- **工程骨架**：27 个 Maven 模块，上下文 × 六边形分层（api / domain / application / infrastructure / interfaces）
- **Identity 完整参考实现**：注册、登录、课程与成员关系、角色与权限
- **共享内核**：领域异常、Actor、集成事件契约、分页、UTC 时间与脱敏工具
- **横切机制**：事务性发件箱与中继、服务端会话（Redis）、全局异常处理、Flyway 迁移
- **中间件**：`deploy/docker-compose.yml`（MySQL 8 带 ngram 分词 + Redis 7）
- **CI 初版**：编译 + 单测 + ArchUnit（FF-1~FF-6）+ 前端构建
- **文档**：ADR 001–009、团队章程、5 份成员介绍、Product Backlog v1.0、DDD 术语表

## 部署

```bash
docker compose -f deploy/docker-compose.yml up -d mysql redis
cd backend && mvn spring-boot:run -pl co-bootstrap -Dspring-boot.run.profiles=dev
cd frontend && npm install && npm run dev   # http://localhost:5173
```
