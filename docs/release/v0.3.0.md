## 概述

问答行为能异步转化为声誉、徽章、悬赏与排行榜：采纳 +15、投票计分与每日上限、悬赏冻结与结算、到期退款。
本次同时把 Sprint 2 的全部工程文档同步进主干。

## 新功能

- **声誉与激励**（PB-20 ~ PB-28）：账户开立（教师初始 1000 分）、采纳 +15（自问自答不加分）、
  被赞 +10 / 被踩 −2 / 每日正向 ≤ 200、徽章、排行榜（周/月/学期/总）、声誉档案与流水、每日对账
- **悬赏**（PB-24、PB-25）：发起 10–500 分 / 1–14 天并冻结积分；采纳自动结算，到期自动退款
- **前端**（PB-29）：悬赏发起对话框与倒计时（#79）
- **搜索投影修复**（#64，PB-32）：只统计问题本身的投票，不再把回答的投票算进去

## 质量与构建

- JDBC `characterEncoding` 改为 `UTF-8`，修复后端无法启动（`#63`）
